◆ isCompartmentViolated()

bool IrObstacleSensor::isCompartmentViolated ( ) const

Avalia o estado de violacao da carga monitorada.

Compartimento fechado: reflexao continua (carga integra). Compartimento aberto: feixe desimpedido, saida em nivel ALTO (violacao!).

Returns
true se a carga foi aberta/violada; false se estiver integra e segura.

◆ isObstacleDetected()

bool IrObstacleSensor::isObstacleDetected ( ) const

Verifica se um obstaculo/reflexao infravermelha esta presente.

No sensor HW-201 (LM393), quando ha reflexao a saida vai para nivel BAIXO (0V).

Returns
true se reflexao detectada (leitura abaixo do limiar); false caso contrario.
